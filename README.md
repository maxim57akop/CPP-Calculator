# CPP-Calculator

Простое консольное приложение для выполнения базовых арифметических операций на языке C++.

## Описание проекта

Программа считывает математическое выражение в формате:

```text
number operator number
```

Например:

```text
3 + 4
10 / 2
7 * 8
```

После ввода программа вычисляет результат и выводит его в консоль.

## Поддерживаемые операции

- Сложение: `+`
- Вычитание: `-`
- Умножение: `*`
- Деление: `/`

## Поведение программы

- При корректном вводе выводит результат.
- Если введён неверный формат, показывает сообщение об ошибке.
- Если выполняется деление на ноль, программа сообщает об ошибке и завершает работу.
- Если оператор не поддерживается, программа выводит сообщение `Invalid operator.`

## Как запустить

### 1. Скомпилировать проект

```bash
clang++ main.cpp -o main
```

### 2. Запустить программу

```bash
./main
```

### 3. Ввести выражение

```text
Enter a mathematical expression (e.g., 3 + 4): 12 + 7
```

Пример вывода:

```text
Result: 19
```

## Структура проекта

- `main.cpp` — основной исходный код калькулятора.
- `main` — скомпилированный исполняемый файл.

## Пример использования

```bash
./main
Enter a mathematical expression (e.g., 3 + 4): 15 / 3
Result: 5
```

## Требования

- Компилятор C++ (например, `clang++` или `g++`)
- Терминал или командная строка

## Автор

Проект создан в учебных/демонстрационных целях для работы с базовыми арифметическими вычислениями на C++.
